# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh


Movies App is a modern web application built with React and powered by TMDB API for dynamic movie data. The application lets users explore trending and popular movies, view detailed information about each movie, and watch official trailers using an embedded YouTube player inside a responsive modal interface. It features smooth routing with React Router, automatic scroll-to-top behavior on navigation, and image fallback handling for missing posters. The layout is fully responsive, providing a consistent experience on both desktop and mobile devices with clean styling using SCSS.
